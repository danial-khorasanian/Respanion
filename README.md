# Respanion
[Respanion](https://www.respanion.com) is an artificial research companion that aims to boost pace and creativity in AI research.
Its first product, "Projects App", is a web application to help AI researchers organize their references and projects, stay up to date, and use the most advanced AI agents to automate research tasks.
